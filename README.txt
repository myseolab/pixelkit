PIXELKIT DEPLOYMENT
1. Create a public GitHub repository named pixelkit under myseolab.
2. Upload all HTML files, app.js, style.css, sitemap.xml to repository root.
3. Settings > Pages > Deploy from branch > main / (root).
4. Visit https://myseolab.github.io/pixelkit/
Note: GitHub Pages restrictions apply to commercial/advertising use. Consider compliant hosting before monetization.
